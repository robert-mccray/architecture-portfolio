# 🏛️ Enterprise Architecture & Systems Gallery

A macro view of governed topologies, data flows, and security meshes for highly regulated environments. 

![Portfolio Preview](./portfolio-preview.png)

### 🎯 The Purpose
This repository houses the frontend architecture for my interactive systems gallery. It is designed to bridge the gap between high-level executive business requirements and deep technical execution. It showcases production-ready patterns for multi-tenant data isolation, Shift-Left FinOps, and Zero-Trust egress governance.

### 🛠️ Tech Stack & Architecture
* **Framework:** React + Vite (TypeScript)
* **Styling:** Tailwind CSS for rapid, scalable UI component design.
* **Routing:** React Router DOM for seamless client-side navigation.
* **Deployment (Edge CI/CD):** Fully automated deployment pipeline via Cloudflare Pages, pushing the compiled assets to the edge for global, low-latency access.
